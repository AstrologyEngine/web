## Agent skills

### Issue tracker

Issues and specs live in the private GitHub issue tracker `AstrologyEngine/web-issues`.
Code and pull requests stay in `AstrologyEngine/web`; always specify the issue
tracker repository in issue commands. See `docs/agents/issue-tracker.md`.

### Triage labels

Use the five default triage labels in `AstrologyEngine/web-issues`.
See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout: root `GLOSSARY.md` and `docs/adr/`.
See `docs/agents/domain.md`.
